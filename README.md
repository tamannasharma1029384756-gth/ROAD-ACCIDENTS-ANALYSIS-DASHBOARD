The Road Accidents Analysis Dashboard is an interactive data visualization project developed using Microsoft Power BI to analyze and understand patterns in road accidents. The dashboard provides insights into accident frequency, severity, location trends, and contributing factors to help stakeholders identify high-risk areas and improve road safety measures. The dashboard consolidates accident data from multiple sources and presents it through dynamic visualizations such as charts, maps, and KPI indicators. Users can filter the data by year, region, vehicle type, weather conditions, and accident severity to explore trends and patterns effectively. Key insights displayed in the dashboard include the total number of accidents, fatalities, and injuries, as well as comparisons across different time periods. It also highlights accident hotspots, the most common causes of accidents, and the types of vehicles most frequently involved. This helps authorities, researchers, and policymakers better understand accident trends and make data-driven decisions. The project demonstrates the use of data cleaning, transformation, and modeling techniques along with advanced Power BI features such as interactive filters, drill-down analysis, and visual storytelling. The dashboard serves as a practical example of how data analytics can be applied to improve road safety and support strategic planning.
